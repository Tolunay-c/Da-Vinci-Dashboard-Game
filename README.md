## ✨ Features

- **📊 Interactive Dashboard** - Real-time data visualization with Chart.js
- **👥 User Management** - Complete CRUD operations for user management
- **📱 Responsive Design** - Mobile-first approach with Tailwind CSS
- **🔍 Advanced Search & Filtering** - Smart user search and pagination
- **📈 Analytics & Charts** - Gender distribution charts and user statistics
- **🎨 Modern UI/UX** - Clean and intuitive interface design
- **⚡ Real-time Updates** - Instant data refresh without page reload

## 🛠 Tech Stack

### Frontend
- **React 18** - Modern React with hooks
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **Chart.js** - Interactive data visualization
- **Lucide React** - Beautiful SVG icons
- **Vite** - Fast development build tool

### Backend
- **NestJS** - Progressive Node.js framework
- **TypeScript** - Full type safety
- **REST API** - RESTful architecture
- **Class Validator** - Request validation

## 🚀 Installation 
   for back-end
    open terminal
      cd ./back-end
      npm i 

   for front-end
    open terminal
      cd ./front-end
      npm i 

## 💻 Development

 ### 🔧 Start Backend Server
    for back-end
    open terminal
      cd ./back-end
      npm run start:dev

  ### 🎨 Start Frontend Server
    for back-end
    open terminal
      cd ./front-end
      npm run dev
